Anhang: Docker-Befehle ​

Befehle und Optionen aus den Übungen an Tag 1. api steht für einen Containernamen.

Container starten ​

Befehl bzw. OptionBedeutung
docker run <image>Container aus einem Image erzeugen und starten; fehlt das Image lokal, wird es zuerst geladen
-dim Hintergrund starten; die Eingabeaufforderung kehrt sofort zurück, die Ausgabe zeigt docker logs
--name apifester Name; ohne die Option vergibt Docker einen zufälligen Namen
-e NAME=wertUmgebungsvariable im Container setzen
-p 8090:8080Port 8090 des Rechners auf Port 8080 im Container weiterleiten (Rechner:Container)
-v api-logs:/var/log/appbenanntes Volume api-logs unter /var/log/app einbinden
-v ${PWD}\logs:/var/log/appVerzeichnis logs im aktuellen Verzeichnis einbinden (Bind Mount, PowerShell)
--rmContainer nach dem Ende automatisch entfernen

Container untersuchen und verwalten ​

Befehl bzw. OptionBedeutung
docker pslaufende Container
docker ps -aalle Container, auch beendete, mit Status und Exit-Code
docker logs apiStandardausgabe und Fehlerausgabe des Containers
docker exec api <befehl>einen Befehl im laufenden Container ausführen
docker exec -it api shShell im laufenden Container; -i hält die Eingabe offen, -t stellt ein Terminal bereit; exit beendet die Shell
docker diff apiÄnderungen im Dateisystem gegenüber dem Image (A hinzugefügt, C geändert, D gelöscht)
docker stop api / docker start apiContainer anhalten bzw. wieder starten; der Inhalt bleibt erhalten
docker rm apibeendeten Container entfernen
docker rm -f apiContainer entfernen, auch wenn er läuft (-f = force)

Images und Volumes ​

Befehl bzw. OptionBedeutung
docker history <image>Schichten des Images mit den Anweisungen, aus denen sie entstanden sind
docker image inspect <image> --format "…"Metadaten des Images; --format wählt einzelne Felder aus
docker volume rm api-logsVolume löschen; nur möglich, wenn kein Container es verwendet

Docker Compose ​

Befehl bzw. OptionBedeutung
docker compose up -dalle Dienste aus compose.yaml im aktuellen Verzeichnis im Hintergrund starten
docker compose up -d --scale api=2wie oben, Dienst api mit zwei Instanzen
docker compose psContainer des Projekts mit Status
docker compose down -vContainer und Netzwerk entfernen, mit -v auch die Volumes
